# Cinema Ticketing and Snack Ordering System

A simple console-based Python application for managing movie ticket bookings and snack purchases.

## Features
- View available movie listings with timing and ticket pricing.
- Select seats using an interactive seat map tracking availability.
- Option to purchase food and beverages (snacks) with customizable quantities.
- Detailed final billing and receipt generation.

## How to Run
1. Ensure Python is installed on your system.
2. Run the script using a terminal or command prompt:
   ```bash
   python cinema_system.py
